# Tutorials

These tutorials cover part of what TORTOISE can do; more will be added over time.

Work through them in order — each assumes the previous ones. Every tutorial is a
self-contained `main.cpp`, built the same way as any project using the library
(see the [root README](../../README.md) for build settings).

Tutorials 4 and 5 produce graphical output, which requires a working GNUPlot
installation with its path set in `TORTOISE/include/Configuration`.
